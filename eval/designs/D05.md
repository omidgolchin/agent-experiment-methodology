# Action formats for a household-task agent

**Question.** Does a JSON function-calling format change an agent's success on text-based household tasks compared with free-text actions?

**Design.** 250 tasks in a text-based household simulator. Each task is run once per condition, with the same model and settings.

- *Free text:* the agent writes its action as a sentence, which a parser maps to the simulator's commands.
- *JSON:* the agent must issue the simulator's commands as JSON function calls.

An episode ends early with an error if the agent produces an action that cannot be parsed. In the pilot, 3% of free-text episodes and 22% of JSON episodes ended this way.

**Exclusions.** Episodes that end with a parse error are dropped and not re-run.

**Outcome.** Task success among the remaining episodes.

**Analysis.** Compare success rates between formats using all tasks with a completed episode in that condition.
