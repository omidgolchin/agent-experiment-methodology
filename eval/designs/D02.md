# A documentation-search tool for a coding agent

**Question.** Does giving a coding agent a documentation-search tool improve its success on library-migration tasks?

**Design.** 240 tasks, each asking the agent to update a small repository to a new major version of a library. Tasks are randomly assigned, 120 per condition, to a configuration with or without a `search_docs` tool; the model, prompts, other tools and step limit are identical. Each repository is restored from a snapshot before its run, and hidden tests check the result.

**Outcome.** Whether the hidden tests pass.

**Analysis.** An agent that never calls `search_docs` has not actually received the treatment, so the treatment group in the primary analysis includes only runs in which the agent called the tool at least once. We compare pass rates between these runs and all control runs with a two-proportion z-test.
