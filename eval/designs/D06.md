# A new system prompt for a customer-support agent

**Question.** Does a new system prompt make a customer-support agent more helpful?

**Design.** 120 support scenarios. In each, a simulated customer (a fixed model, prompt and seed per scenario) chats with the support agent twice: once with the current system prompt and once with the new one. The support agent uses the same model in both.

**Outcome.** Each conversation is scored 1–10 by a second LLM acting as judge. The judge prompt reads: "You are evaluating a conversation handled by our NEW improved support agent (or by the OLD agent). Rate its helpfulness from 1 to 10." The condition name is filled in for each conversation. The judge has not been compared with human ratings.

**Analysis.** Paired t-test on judge scores. A higher mean for the new prompt will be taken as evidence that it makes the agent more helpful.
