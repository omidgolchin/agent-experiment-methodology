# Polite personas in LLM negotiation

**Question.** Does giving LLM negotiation agents a polite persona increase the rate of reaching an agreement?

**Design.** Two LLM agents negotiate the sale of a used car: a buyer and a seller, each with a private reservation price. The seller agent is assigned either a neutral persona or a polite persona (one added sentence in its system prompt). We run 400 negotiations per condition, all using this one used-car scenario with the same prices, varying only the random seed.

**Outcome.** Whether a deal is reached within 10 rounds, detected by script.

**Analysis.** Difference in agreement rates with a two-proportion z-test on n = 800. We will report the result as evidence that polite personas increase agreement in LLM negotiation tasks.
