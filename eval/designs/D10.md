# A memory module for a support agent

**Question.** Does a long-term memory module improve a customer-support agent?

**Design.** 500 simulated customers, each with a history of three earlier support tickets generated in advance, are randomly assigned to a support agent with or without a memory module that stores notes from the customer's earlier tickets. Each customer then opens one new ticket and chats with the agent.

**Outcomes.** Resolution rate, number of turns, simulated-customer satisfaction, politeness, factual errors, policy violations, escalations to a human, cost and latency. Each outcome will also be examined separately for each of the four ticket categories.

**Analysis.** For each outcome and category, a t-test between conditions. We will report the outcomes and categories where memory shows a statistically significant benefit (p < .05) as the effects of memory.
