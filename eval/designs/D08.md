# A planning prompt for a web-research agent

**Question.** Does a new planning prompt improve a web-research agent's accuracy on multi-step questions?

**Design.** 200 questions with gold answers. The agent can search the live web and read pages. Same model name through the provider's API, temperature 0.

- All control runs (current prompt) were collected in the first week of October.
- Budget approval for the treatment arm came later, so all treatment runs (new prompt) are collected in the second week of November.

We do not pin a model snapshot; the provider updates the model behind the name from time to time.

**Outcome.** Exact match with the gold answer, checked by script.

**Analysis.** Compare accuracy between the two prompts.
