# Site maps for web-shopping agents

**Question.** Does adding a site map (a short list of the website's pages and what each contains) to a web-shopping agent's prompt improve its task success?

**Pilot.** We ran 120 candidate tasks on a sandboxed shopping website, three times with and three times without the site map. We kept the 25 tasks on which the site map produced the largest improvement in success.

**Main study.** The 25 retained tasks are each run 10 times per condition with new seeds, the same model and settings, and a randomized, interleaved run order.

**Analysis.** Pre-registered mixed-effects logistic regression of success on condition, with random intercepts for tasks. We will report the main study as a confirmatory test that site maps improve web-shopping agents.
