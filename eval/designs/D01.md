# Demonstrations for a travel-booking agent

**Question.** Does adding one demonstration trajectory to a tool-using agent's prompt improve its success on travel-booking tasks?

**Design.** 150 tasks in a simulated travel-booking environment with flight-search, hotel-search and booking tools. The environment is sandboxed and reset before every run. Each task is run once in each condition with the same model and temperature (0.7).

- *Control:* the system prompt describes the tools and the task. Step limit: 15 tool calls.
- *Treatment:* the same system prompt plus one demonstration (a complete, successful trajectory on a different task), followed by "Plan all the steps before your first tool call." Step limit: 40 tool calls.

**Outcome.** Whether the final booking satisfies all of the task's constraints, checked by script against the environment's database.

**Analysis.** Paired comparison of success rates across the two conditions, clustered by task. We will conclude that demonstrations improve tool-using agents if the treatment is significantly better.
